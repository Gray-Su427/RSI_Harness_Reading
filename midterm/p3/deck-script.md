## P1 · 0:00–0:20 ｜结论

【做】站定，不寒暄，不自我介绍。开口就是结论。

【说】

> 先给结论。19 篇文献，我们挑出 9 篇做了分类。9 篇里 6 篇改的是代码，去掉两篇不算 harness 的还有 4 篇。但只有 3 篇说清楚自己递归到哪一层，剩下 5 篇作者没界定。保证这块，形式化只有 SEVerA，自偏好只有 RHO。**高递归、高保证同时做到的一篇都没有。**

【做】说完立刻翻页。不要停在封面上解释标题。

## P3 · 0:55–1:55 ｜分类：一张图怎么读

【做】先沿横轴划一次，再沿纵轴划一次，最后指底部灰带。**这一页不报任何结论数字。**

【说】

> 怎么看这 9 篇？我们用了五个轴，今天只画两个：横轴是**改什么**，纵轴是**递归到哪一层**。一个点一篇论文，位置就是它在这两根轴上的取值。
>
> 最下面这条灰带，是 5 篇作者自己没说清楚递归到哪一层。按我们的纪律，E 轴只认作者原话，所以不替他们填，先放在灰带里。
>
> 读的时候三步：**先看哪一列，再看哪一行，最后看是不是在灰带里。**

【若问】“为什么不把灰带里的补上？”→ 项目纪律：E 轴只认作者界定，不代作者下结论。追问细节翻 B2。

## P4 · 1:55–2:35 ｜证据 1：6 篇改代码，4 篇改的是 harness 自己

【做】指 6/9 → 箭头 → 4/9；再指右侧两篇不算进来的。

【说】

> 第一件事，改什么。9 篇里 6 篇的主值是代码，这是最集中的一列。但这里面有 2 篇要单独说：**AlphaEvolve 改的是任务算法，不是它自己；SEVerA 的 Learn 阶段改的是模型权重。** 把这两篇拿掉，还有 4 篇，代码仍然是最大的一类。
>
> 所以“大家在改代码”这个判断成立；**但改代码，不等于递归到哪一层。**

【若问】“ADAS 算哪边？”→ A 值有 control-flow / code 两读；若记 code，会变成 7/9，精读时要定。

## P5 · 2:35–3:15 ｜证据 2：只有 3 篇说清递归到哪层

【做】指 3 → 1 → 5，最后停在底部深蓝条。

【说】

> 第二件事，递归到哪一层。只有 3 篇能对上号：**STOP 是 iterative，DGM 是 full-rsi 但只在代码层，RHO 是 one-shot。** SICA 自称 fully self-improving，我们先记候选。
>
> 剩下 5 篇——ADAS、AlphaEvolve、SEVerA、Harness≠Benefit、MGM——作者没界定，我们不替他们填。所以 **co-evolution 现在只能写 0 篇确认，不能写“领域里没有”。** 0 是“没人确认”，不是“没人做”。
>
> RHSI 说自己 co-evolution，但作者只做完了循环的前半段，我们没算。

【若问】“多轮为什么不等于 full RSI？”→ 只看改进后的系统参与什么：搜产物 vs 改下一轮的程序。翻 B1 ③。

## P6 · 3:15–4:10 ｜证据 3 与争议：能更新，不等于有收益

【做】语气从“我们发现了”转成“我们可能错”。三行各 15–18 秒，不展开论证。

【说】

> 第三件事，凭什么信。我们看三个地方。
>
> **第一，收益。** 9 篇里，把选择偏差、验证集过拟合、基准污染拆开报的，我们没找到。下一步 7 篇精读，就查有没有 hold-out、有没有报尝试次数。
>
> **第二，验证器。** 形式化只有 SEVerA，它自己说不管 token 和时间；自偏好只有 RHO，作者自己报告最偏好的 0.78 不是最高的 0.85。它保证的是不劣于基线，不是验证独立。
>
> **第三，成本。** DGM 报美元，SICA 报轮次，AlphaEvolve 报 compute-hours，RHO 报 agent calls——四种单位，没法直接比。所以我们不做效率结论。
>
> **这三条，就是 7 篇精读的检查表。**

【若问】“SEVerA 不是有形式化保证吗？”→ 只覆盖给定规格下的功能正确；作者自陈 resource-unaware，不含 LLM calls / token / wall-clock。翻 B1 ⑥。
