## P5 · 三个争议（55 s）

**Q1 · 能更新 ≠ 有收益**（出处 `arxiv-2605.30621`）
- 立场：先拆选择偏差、验证集过拟合、基准污染，再谈增益
- 如果我错了：增益可独立复现 → 领域核心叙事成立，本综述价值回到分类与设计空间

**Q2 · 验证器是否独立于被优化对象**（出处 RHO `arxiv-2606.05922`、SEVerA `arxiv-2603.25111`）
- 立场：RHO 的 self-preference 给的是「不劣于基线」的安全网，不是「验证独立」；作者自报最偏好 0.78 ≠ 测试最高 0.85。SEVerA 的 formal 只覆盖功能规格，不含 LLM calls / token / wall-clock
- 如果我错了：自偏好 + 形式化都能在无标注部署下成立 → 这是实用性突破，不是循环论证

**Q3 · 成本是否被扣除**（出处 DGM $22k / 2 周；RHO 103 vs 41 vs 320 agent calls；多数未报告）
- 立场：缺项一律标「部分报告 / 未找到」，不作效率结论
- 如果我错了：所有工作同口径报告成本且仍有增益 → 本条作废

**讲稿（55 s）**：
> 「三个争议，按'结论可信吗、机制自洽吗、比较公平吗'递进。
> Q1：能更新不等于有收益，要把选择偏差、验证集过拟合、基准污染拆开。
> Q2：验证器是不是独立的？RHO 用自偏好，作者自己承认最偏好的方案不是测试最高的——0.78 对 0.85；SEVerA 有形式化保证，但只保功能正确，不保预算。
> Q3：成本。DGM 报了两万两千美元两周，RHO 给了唯一一组同口径 agent calls，其余多数没报——所以我们不做效率结论。」
