## R1 · Venue 未核验，同行评审指标尚未闭环

- **当前证据**：CSV 中 17 篇条目的 `venue_verified` 均为 `false`。STOP、ADAS、DGM 的会议字段不能直接作为独立核验结果。
- **影响**：可能把 preprint 误称为会议论文；课程“至少一篇经典／高质量同行评审”项无法验收。
- **负责人**：P1（xyc）；P4（zgj）跟踪，P3（szh）负责 deck 表述。
- **应对**：P1（xyc）优先检索 STOP、ADAS 的 OpenReview／DBLP 正式条目，同时按 CP1 核验 DGM、SICA；逐项记录论文标题、会议、年份、录用状态、来源 URL 和查询日期。只有足够证据才更新 `venue_verified: true`。若 T−2 未闭环，D1—D2 先补验 venue，再进入 Schema。
- **时限**：T−2 天 CP1；若未闭环，按规则保留 CP1 未通过状态，提交阻塞原因。
- **降级口径**：“同行评审候选，venue 待独立核验”；不宣称课程指标已达标。若确实无合格项，P1（xyc）提出已核验替代候选，由全员确认并留变更记录。
- **退出条件**：至少一篇正式同行评审论文有可追溯核验来源；四篇 seed 均有核验结论。核验失败也需记录，不等于四篇必须全部是会议论文。

## R2 · 算力成本未完整报告，无法判断净收益

- **当前证据**：skim 卡记载 STOP 仅有渐近预算，AlphaEvolve 缺整轮搜索总成本；P4 论文 §4.1 声明各配对共享预算，但这本身不能证明同美元、同 token 或净成本收益相同。DGM、ADAS、RHO、SEVerA 已有不同粒度成本信息，应分别回查。
- **影响**：性能提升可能来自更多采样或额外评测；不同论文的美元、agent calls、耗时不能直接汇总排名。
- **负责人**：P4（zgj）汇总，各篇负责人补证据。
- **应对**：统一摘录搜索／更新／最终推理成本、模型版本、调用与 token、运行时间、硬件、任务数、轮数及预算上限；区分作者实测、作者估算和本组估算。检查固定模型同预算搜索基线；不能补造缺失金额。
- **时限**：D7 列出缺项；D11 完成附录／代码回查；D14 固化成本可比范围。
- **降级口径**：缺项标“部分报告”或“未找到”，只比较可比的性能证据；不宣称更便宜或净收益更高。复现实验先用小样本估计成本，再由组员确认可承受范围。
- **退出条件**：七篇均有成本证据位置或明确缺失记录；所有效率主张有同口径分母和基线。

## R3 · 复现性不足，代码公开不等于结论可重现

- **当前证据**：部分方法依赖闭源模型、历史 API 或未确认发布的 archive。P4 论文的代码链接本次已从 arXiv 找到，且 GitHub 对应分支可访问；尚未安装、运行或复现实验。
- **影响**：无法审查完整选择过程、失败样本、随机性和模型版本漂移；只看到最终最优结果可能高估证据强度。
- **负责人**：各篇阅读负责人检查各自材料；P4（zgj）汇总；P2（zyc）关注方法比较时的可复现等级。
- **应对**：登记代码 URL、commit、许可证、模型版本、依赖、数据切分、配置、随机种子、diff／trajectory／archive；区分“作者称开源”“链接可访问”“小样本可运行”“主结果已复现”。先做一篇可运行性检查，再视时间和费用决定是否扩展。
- **时限**：D4 核实首轮论文入口；D9 补齐七篇公开材料状态；D14 登记实际运行与未复现原因。
- **降级口径**：保留为文献证据并明确复现限制；未运行写 `unknown`，不直接填 `reproducible: true` 或断言不可复现。
- **退出条件**：七篇公开材料及可运行性状态都有依据；任何“已复现”结论有配置、执行日志和结果记录。
