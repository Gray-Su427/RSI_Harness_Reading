# synthesis/ — 综合产出

本目录回答三个问题，对应课程 PPT 第 12 页第三阶段的要求：

| 文件 | 回答 | 数量要求 |
|---|---|---|
| [`open-questions.md`](open-questions.md) | **哪里有争议？** | **2–3 个** |
| [`evidence.md`](evidence.md) | **我们凭什么这么说？** | **≥3 条**，每条附 ≥2 篇 |
| [`taxonomy.md`](taxonomy.md) | **这些工作怎么分类？** | **1 套** |

---

## 构建顺序（不要跳步）

```
open-questions  →  evidence  →  taxonomy  →  README 的 1 句核心结论
```

**为什么是这个顺序？**

1. 争议决定综述的**立场**——没有争议，综述就只是一份目录
2. 证据必须能**独立站住**——先有证据再定分类轴，而不是先定轴再往里填人
3. 分类体系要用**证据反推**得出——反过来做会导致每篇论文都被强行归类
4. 核心结论必须被上面三份文件**同时支撑**——最后写，且要经得起追问

---

## 交付自检

第三阶段完成前逐项确认：

- [ ] `open-questions.md` 有 **2–3** 个争议
- [ ] 每个争议有支撑文献，且能回答"**如果我错了会怎样**"
- [ ] `evidence.md` 有 **≥3** 条证据
- [ ] 每条证据附 **≥2 篇**参考文献，且**互相独立**
- [ ] `taxonomy.md` 可用**一张图**讲清（需要多张 = 还没想清楚）
- [ ] `../README.md` 写出了 **1 句**核心结论（不是一段）

### 证据独立性检验

> 常见的凑数方式：把 DGM 和 MGM 当作两条证据。
> 这两篇的作者团队重叠、问题设定相近、结论互相支持，**只能算一条**。

**判定标准：作者重叠 + 问题设定重叠 + 结论重叠 → 同一族，计为一条。**
