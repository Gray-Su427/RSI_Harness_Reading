## 证据独立性检验

> **最常见的凑数方式**：把 DGM（`arxiv-2505.22954`）和 MGM（`arxiv-2608.07645`）
> 当作两条证据。它们作者团队重叠、问题设定相近、结论互相支持——**只能算一条**。

**判定标准（三者同时满足即视为同族，只计一条）**：

- 问题设定重叠

|---|---|---|---|
| `arxiv-XXXX` | | | |
| `arxiv-YYYY` | | | |

**证据强度**：强 / 中 / 弱
- 强：≥2 篇独立文献 + 至少 1 篇为同行评审 + 有强 baseline 对照
- 中：≥2 篇独立文献，但均为 preprint 或 baseline 较弱
- 弱：仅 1 篇，或文献同族，或无对照实验

**反面证据**：有没有文献不支持这条主张？（**必填**，即使答案是"暂时没找到"）

**如果我错了会怎样**：

## 候选证据方向（来自种子论文的初步观察）

以下仅为**线索**，尚未验证。每条都必须在精读后确认或推翻。

### E? · 进化搜索是当前主流算子

**线索**：STOP / ADAS / SICA / DGM / MGM / AlphaEvolve 六篇中有五篇使用进化或搜索类算子。
**待检验**：这是领域共识，还是仅仅是"容易在 coding 任务上验证"的产物？
**需要的证据**：至少一篇明确**否定**搜索类方法优越性的论文。

### E? · 外部可执行验证是当前唯一可信的验证信号

**线索**：DGM / AlphaEvolve / ADAS 都依赖 benchmark 分数或单元测试。
**反例**：RHO（`arxiv-2606.05922`）论证部署场景下真值验证不可得，改用自偏好。
**待检验**：自偏好路线是否已被证明有效？还是仅是"不得已而为之"？

### E? · 递归深度与改进幅度不成正比

**线索**：E 轴上 `full-rsi` 仅 DGM 一篇，其余多为 `iterative` / `one-shot`。
**待检验**：更深的递归是否真的带来更大收益？STOP 作者的"这不算完整 RSI"表态
是否暗示递归深度的营销成分大于实质？
